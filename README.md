# 🇧🇷 Brasileiros no Canadá — Análise Demográfica

Análise exploratória da imigração brasileira para o Canadá usando Python e Pandas.

## 🎯 Objetivo
Responder perguntas sobre evolução, distribuição geográfica, perfil etário e vias de imigração da comunidade brasileira no Canadá.

## 📊 Fontes de dados
- Immigration to Canada by Country of Origin (Keggle)

## 🛠 Tecnologias
- Python 3.10+
- Pandas
- Matplotlib

## ▶️ Como rodar
```bash
pip install -r requirements.txt
python analise_brasileiros_canada.py
