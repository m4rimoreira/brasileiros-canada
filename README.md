# 🇧🇷 Brasileiros no Canadá — Análise Demográfica

Análise exploratória da imigração brasileira para o Canadá usando Python e Pandas.

## 🎯 Objetivo
Responder perguntas sobre evolução, distribuição geográfica, perfil etário e vias de imigração da comunidade brasileira no Canadá.

## 📊 Fontes de dados
- Immigration to Canada by Country of Origin (Keggle)## 📊 Fonte dos dados

- **Origem oficial:** Immigration, Refugees and Citizenship Canada (IRCC)
- **Portal:** [open.canada.ca](https://open.canada.ca/data/en/dataset/f7e5498e-0ad8-4417-85c9-9b8aff9b9eda)
- **Consolidação:** dataset "Immigration to Canada by Country of Origin" no Kaggle
  ([link](https://www.kaggle.com/datasets/aliranjipour/immigration-to-canada-by-country-of-origin))
- **Período:** 1980–2024
- **Variável:** admissões anuais de residentes permanentes por país de cidadania

## 🛠 Tecnologias
- Python 3.10+
- Pandas
- Matplotlib
